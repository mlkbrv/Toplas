# Toplaş

**Discover. Connect. Experience.**

A premium, frontend-only mobile app for discovering local events, communities, and
opportunities — built with React Native (Expo) and TypeScript. Dark, flat-2D visual
identity with electric-violet accents. **No backend: all content is mock data.**

Fully bilingual: **English** and **Azerbaijani** (device locale is auto-detected; switch
anytime in Settings → Language).

## Run it

Dependencies are already installed. Start the dev server:

```bash
npm start
```

Then:
- Press `i` for the iOS simulator (macOS), `a` for an Android emulator, or `w` for web.
- Or scan the QR code with the **Expo Go** app on your phone.

## Backend (MVP)

A lightweight **Express** backend lives in `server/` — in-memory store, seeded
from the app's own data (`server/seed.json`, generated by `scripts/exportSeed.ts`,
so API shapes match the app exactly). It exposes events, communities, organizers,
opportunities, mentors, businesses, notifications, auth (demo), and booking /
save / join mutations.

Run it (separate terminal):

```bash
cd server
npm install
npm start          # http://localhost:4000  (GET /api/health)
```

Then point the app at it (optional — the app falls back to local mock data when
the backend is unreachable, so it always runs):

```bash
EXPO_PUBLIC_API_URL=http://localhost:4000 npm start
```

When connected, the home header shows a green **Live** badge; offline it shows
**Demo**. Registering for an event and saving/joining sync to the backend
best-effort. Regenerate the seed after changing app data:

```bash
npx tsx scripts/exportSeed.ts
```

> Android emulator: use `http://10.0.2.2:4000`. Physical device: your machine's LAN IP.

## What's inside

14 primary screens plus modals, filter sheets, booking confirmations, empty/loading states:

Discover · Explore (list + stylized map + filters) · Event Details · Communities ·
Inbox & Chat · Profile · My Events & Tickets · Surprise Me · Create Event ·
Organizer Dashboard · Business Profile & Rewards · Opportunities & Mentors ·
Notifications · Settings & Privacy.

A connected journey works end-to-end on mock data: discover an event → view details →
register → get a QR ticket → manage the booking in My Events.

## Project structure

```
App.tsx                    Providers (fonts, i18n, state, navigation), dark theme
src/
  theme/                   Design tokens: colors, spacing, radii, typography, motion
  i18n/                    i18next config + en/az resources + useLocale() hook
  data/                    Typed mock data (events, communities, mentors, …) + helpers
  state/                   AppProvider — saved/registered/joined/followed state
  components/ui/           Reusable primitives (Button, Chip, Card, BottomSheet, …)
  components/cards/        Domain cards (EventCard, CommunityCard, TicketCard, …)
  navigation/              Bottom tabs (floating glass bar) + native stack
  screens/                 All screens
```

## Notes

- **Mock data only.** Sample listings are clearly demo content, not real events.
- **Images** use deterministic placeholder services (`picsum.photos`, `pravatar.cc`) so
  every image loads offline-friendly. Swap the helpers in `src/data/images.ts` for curated
  event photography without touching screens.
- The **map** in Explore is a stylized 2D abstraction (no real GPS / maps SDK).
- Micro-interactions use React Native's built-in `Animated` and respect reduce-motion.
